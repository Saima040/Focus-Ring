# Changelog

## 1.0.0
- 50 worlds and 175 levels.
- Sun/moon theme switch that remembers your choice.
- Funny cartoon focus ring and a colorful speaker button.
- Star scoring (par, par + 3), best-run records and a clock on some levels.
- Phone support with an on-screen keyboard.
- Tools: solver check, real-browser replay, level list export, screenshots.

# Every level, listed

All **175 levels** in **50 worlds**, in play order. *Par* is the fewest key presses that can win the level, found by a computer search, so three stars always means a perfect route. *Clock* is the number of key presses you get before the page closes (a dash means no clock). Solutions are hidden behind a click so you can try first.

**Key shorthand in the solutions:** `Tab` Tab, `⇧Tab` Shift+Tab, `Enter`, `Space`, `←` and `→` the arrow keys, `Esc`.
